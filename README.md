# Dragon Park

**Садись в седло — и полетим.**

Сумеречный круг по парку на добром драконе с седлом. Собирай звёзды и угли, открывай сундуки, пролетай через озеро, карусель, луг и замок. Восемьдесят секунд на лучший счёт.

## Как играть

1. Открой `index.html` в браузере.
2. Нажми **В седло**.
3. Лети **WASD** или стрелками. **Пробел** — рывок.
4. На телефоне: стик слева, рывок справа.
5. Комбо растёт, если не давать свету остыть.

Рекорд пишется в `localStorage`.
