# Dragon Park

**Садись в седло — и полетим.**

Сумеречный круг по парку на добром драконе с седлом. Ночь фонарей: собирай звёзды, угли, фонари и сундуки, пролетай через озеро, колесо, карусель, луг, рынок, обсерваторию и замок.

## Как играть

1. Открой `index.html` в браузере.
2. Нажми **В седло**.
3. Лети **WASD** или стрелками. **Пробел** — рывок (следи за шкалой).
4. На телефоне: стик слева, рывок справа.
5. Комбо растёт, если не давать свету остыть.
6. **Escape** — пауза.

Рекорд пишется в `localStorage` (`dragon-park-save`).

## v3 — lantern night

Продолжение сумеречного круга:

- Семь ориентиров с бонусами, включая колесо, рынок и обсерваторию
- Фонари, что медленно всплывают в сумерках
- Мини-карта, шкала рывка, комбо
- Частицы, встряска камеры, всплывающие очки
- Звук (Web Audio) — выключается кнопкой
