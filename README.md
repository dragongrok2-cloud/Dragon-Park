# 🐉 Dragon Park

**Садись в седло и полетим вместе!**

Добро пожаловать в **Dragon Park** — милую браузерную игру, где ты управляешь добрым драконом с седлом!

## 🎮 Об игре

Ты — наездник на дружелюбном красном драконе. Летай по парку, собирай золотые звёзды и набирай очки, пока не закончится время!

### Как играть
1. Открой [index.html](index.html) в браузере (или через GitHub Pages)
2. Нажми **«Начать игру!»**
3. Управляй драконом стрелками ←↑→↓ или клавишами **WASD**
4. Собирай звёзды ⭐
5. У тебя есть 60 секунд — успей набрать как можно больше очков!

## 🚀 Возможности
- Красивый парк с деревьями и облаками
- Милый дракон с **седлом** (самое важное!)
- Собираемые пульсирующие звёзды
- Весёлые сообщения от дракона
- Таймер и счётчик очков
